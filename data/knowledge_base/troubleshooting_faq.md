# Troubleshooting FAQ

## Common Technical Issues
- If the app is not loading, ask the user to refresh the browser and check the internet connection.
- If the customer cannot log in, verify the username and password and use the password reset function.
- If the customer reports a billing mismatch, confirm the subscription plan and billing date before answering.

## When to Ask for More Information
Ask for more information when the ticket does not include enough detail to diagnose the issue, such as:
- the device or browser being used,
- the date the issue started,
- the exact error message,
- or the account identifier.

## Escalation Guidance
Escalate when the issue is outside standard troubleshooting steps or requires account-specific investigation.
